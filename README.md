# Sorting Algorithms & Big O

This project contains implementations of various sorting algorithms in C, as part of the low-level programming curriculum.

## Algorithms Included:
* **0. Bubble Sort** - An (n^2)$ sorting algorithm that repeatedly steps through the list.
* **1. Insertion Sort** - An (n^2)$ algorithm that builds the final sorted array one item at a time.

## Requirements
* All files compiled on Ubuntu 20.04 LTS using `gcc`
* Allowed editors: `vi`, `vim`, `emacs`
* Code follows the **Betty** style.
